# Два навыка: установка и проверка

Версия **0.8.3**. Пользователю предлагаются ровно два самостоятельных навыка:

| Файл | Назначение |
| --- | --- |
| `memory-export.zip` | Установить агенту-упаковщику: он собирает, проверяет и экспортирует данные |
| `memory-import.zip` | Установить получателю с поддержкой навыков; обычный ГигаАгент навыки и архивы не принимает |

Каждый ZIP содержит свои инструкции и весь необходимый код. Для одной роли достаточно одного навыка; объединённый комплект не требуется. При обновлении замените прежнюю версию соответствующего навыка. Экспортный комплект также содержит установщик импорта для передачи получателю; второй навык автоматически не включается. Файлы с экспортированными данными пользователя передаются отдельно от установочного ZIP.

[Завершение экспорта 0.8.3](EXPORT_COMPLETION.md) · [Сценарий и форматы 0.8](UX_REVIEW_V08.md). Возможность установки, выполнение Python и доступ к файлам проверяются в выбранном аккаунте. Описанные ниже официальные каналы установки не заменяют живой тест в этом аккаунте.

Карта источников описана в [JOURNEY_V02.md](JOURNEY_V02.md), доказательства профиля — в [PROFILE_REVIEW.md](PROFILE_REVIEW.md), пользовательские инструкции и оригиналы навыков — в [INSTRUCTIONS_AND_SKILLS.md](INSTRUCTIONS_AND_SKILLS.md). Почтовое и фоновое ожидание отложены; рабочий путь передачи описан в [CLOUD_DELIVERY.md](CLOUD_DELIVERY.md).

## Что содержится в проекте

Два навыка используют общее Python-ядро разработки, копия которого включена в каждый установочный ZIP. Пользователю не нужно устанавливать ядро отдельно. Модель собирает сведения, сопоставляет их по смыслу и обсуждает необходимое с пользователем. Программа проверяет охват и актуальность общей проверки, разбирает предоставленные файлы, собирает пакет и готовит переносимое пространство. Установка навыка у каждого источника необязательна: главный агент может получить архивы, тексты и файлы напрямую. Локальный Python не нужен пользователю, если веб-агент предоставляет выполнение Python 3.10+ и создание файлов.

Почту и диски подключают средствами самого агента. Проект не содержит OAuth-сервера, сетевых коннекторов или фонового наблюдателя. Карточка переноса координирует шаги, но сама не читает письма и не скачивает файлы.

Основной сценарий [доставки через папки](CLOUD_DELIVERY.md) предусматривает копирование пользователем и запуск приёма его сообщением. Подключение почты и наблюдатель не являются условиями запуска. Установка двух навыков не создаёт между ними канал связи. Цель веб-пути — [настройка получателя](PRODUCT_GOAL.md) в согласованном объёме; создание ZIP и нативная настройка отмечаются разными результатами.

## Установка по ролям

1. У отправителя установите `memory-export.zip` через поддерживаемый интерфейс навыков. Напишите: «Помоги перенести мой контекст в [название нового агента]. Используй memory-export».
2. После экспорта откройте `NEXT_STEPS.md`: там указаны получатель, реальные имена передаваемых файлов и готовое сообщение для импорта. Выполните соответствующий маршрут ниже.

Если установщик принимает папку, распакуйте соответствующий ZIP и передайте всю папку навыка с кодом и справочниками. Один `SKILL.md` не заменяет полный комплект. Если один агент выполняет обе роли через навыки, установите оба; включение экспортного навыка само по себе не активирует импортный.

Для браузера и десктопа состав навыка одинаков. Проверяется фактический способ установки и набор инструментов конкретного агента; имя продукта не подтверждает поддержку ZIP. Отдельно проверьте чтение файлов, выполнение кода и запись памяти. Папка на ноутбуке не становится доступной веб-агенту автоматически.

### ChatGPT и Claude

- **ChatGPT:** самостоятельные навыки доступны в поддерживаемых средах desktop/CLI/IDE; в вебе используется канал плагинов. Не считайте обычное прикрепление `memory-import.zip` в веб-чат установкой. Используйте фактически доступный канал установки; наличие подходящего веб-плагина в этом комплекте не обещается. [Официальные каналы OpenAI](https://learn.chatgpt.com/docs/build-skills).
- **Claude:** при наличии функции откройте **Customize → Skills → + → Create skill → Upload a skill** и загрузите `memory-import.zip`. Для навыков требуется включённое выполнение кода. [Официальная инструкция Claude](https://support.claude.com/en/articles/12512180-use-skills-in-claude).

Затем приложите саму выгрузку, а не только установщик. Напишите: «Используй memory-import. Проверь приложенные данные, сравни с текущей памятью и импортируй подходящие сведения. Противоречия уточни со мной. Сообщи, что действительно сохранено».

Если постоянная установка недоступна, можно передать **полный** `memory-import.zip` для работы в текущем чате с файлами и кодом либо всю извлечённую папку с `SKILL.md`, `references/`, `assets/` и `scripts/`. Попросите прочитать инструкции и использовать этот комплект для приложенной выгрузки. Один `SKILL.md` не содержит всех правил и программы. Такой запуск не считается установленным навыком; без чтения файлов и выполнения кода программная проверка не выполняется. Сохранение долгосрочной памяти отдельно требует доступных инструментов принимающего агента.

### ГигаАгент Про (ex-Ouroboros)

По указанному пользователем маршруту откройте **Меню**, установите или включите **Amberkeep carry memory**, приложите выбранные файлы экспорта и отправьте сообщение из `NEXT_STEPS.md`. Этот путь не проверен в живом аккаунте; при отсутствии пункта не подменяйте его другим похожим плагином. Приём разных форматов файлов не гарантирует запись памяти, установку навыков или восстановление настроек.

### ГигаАгент

Приложите **только `import-instruction.md` и `client-memory-export.md`** из результата экспорта. Если профиль разбит на несколько соответствующих формату Markdown, приложите все перечисленные файлы профиля. **Обычный ГигаАгент не принимает архивы и навыки:** не отправляйте ему ZIP, установщик или папку навыка и не предлагайте распаковку. Переименование ZIP или JSON в `.md` не делает его совместимым профилем.

`NEXT_STEPS.md` предназначен пользователю, а не для загрузки. Технические отчёты, исходные переписки, навыки и резервные материалы остаются отдельно. Самостоятельная копия `import-instruction.md` также находится в пользовательской папке `Импорт`; она не содержит вашего профиля. Если подготовлен только архив, попросите отправителя создать профиль Markdown по формату памяти ГигаАгента.

Напишите: «Импортируй сведения обо мне в долгосрочную память. Прочитай `import-instruction.md` и все приложенные файлы профиля. Выполни инструкцию: проверь готовые записи вместе с текущей памятью, сохрани подходящие и проверь их чтением. Не ограничивайся пересказом. Начинай».

Обычный Markdown нужно открыть и прочитать, а не распаковать. Импортируется только раздел «Готово к импорту»; инструкция и справочные приложения не становятся фактами о пользователе. Если `memory_list`, `memory_read` или `memory_save` недоступны, агент сообщает, что импорт в долгосрочную память не выполнен. Наличие приложенных файлов без просьбы импортировать не разрешает менять память.

## Первая проверка двух агентов

Использовать вымышленные данные до проверки жизненного цикла:

1. Назначить одного главного агента. Передать доступные вымышленные материалы из двух или трёх источников; сохранить известные выборы. Уточнять только недостающее, а не проходить все подключения заранее.
2. Главный создаёт общее состояние `common-create` и регистрирует источники. `--previous` добавляется только для действительно прежнего подтверждённого профиля; новая выгрузка не может сама назначить себя одобренной.
3. Агент читает объединённый состав, проверяет доказательства, находит смысловые дубли, противоречия и совместимые области. Отдельный проверяющий или честно обозначенный второй проход той же модели сверяет эти выводы. Общий результат регистрируется через `common-review`; Python сам смысл не определяет.
4. Задать необходимые вопросы, записать фактические ответы через `common-event`, сохранить отсрочки. Добавить поздний источник и убедиться, что общий этап обновился, а неизменённые ответы не спрашиваются повторно.
5. Получить `common-result`, затем выполнить `export … --common-store …` и `inspect`. Отдельный `profile-result` или подтверждение одного источника не заменяет этот этап. Точные команды и схемы — в [common-profile.md](../skills/memory-export/references/common-profile.md).
6. Скачать пакет либо разместить его реальным доступным инструментом. Пользователь передаёт файлы и сообщает получателю о готовности; фоновый запуск не предполагается. Получатель проверяет пакет, сравнивает с реально доступной текущей памятью и применяет согласованный план в переносимую папку.
7. Если фактическое объединение у получателя не покрыто входящей общей проверкой, `common_review_required` сохраняет файлы и решения, но блокирует активное применение до новой общей проверки. Отложенные сведения проверенного частичного пакета не активируются. Неизменённые пользовательские решения нужно сохранить, а не собирать заново.
8. Отдельно проверить поддерживаемое сохранение постоянной памяти, установку выбранных навыков и подключения. Неподдерживаемые шаги остаются невыполненными в отчёте. Повторный приём не должен создавать дубли или повторять уже завершённые действия.

Дополнительные случаи: доступ к папке есть у отправителя и отсутствует у получателя; архив ещё не готов; передана неполная папка или старая версия; пользователь изменил правило после подтверждения; новый источник содержит парафраз прежнего правила; личная и проектная инструкции имеют разные области; два независимых чата пытаются вести общий профиль одновременно. Один локальный общий реестр не превращает облачные копии в синхронизированную систему.

## Что считать пройденной проверкой

Автоматические тесты проверяют файловую обработку и правила состояния. Проверка навыка оценивает реальные решения модели. Живой тест в Claude/ChatGPT дополнительно проверяет установку, выполнение скриптов, доступность файлов и возможности аккаунта. До такого теста совместимость с конкретным веб-аккаунтом остаётся непроверенной.

Не требуются настоящие почты или личные архивы для проверки ядра. Для проверки реального коннектора потребуется подключённый аккаунт и разрешение на конкретную операцию; успешная имитация этого не заменяет.

## Только для разработчика

Экспериментальные `portable-memory-plugin.zip` и `memory-web-kit.zip` сохранены для технических испытаний, но исключены из обычной пользовательской поставки. Их можно собрать явно: `python scripts/build_bundles.py --include-extras`; исторический `--web-kit-only` обновляет только веб-комплект. [Ручной веб-запуск](MANUAL_WEB.md) описывает этот технический вариант, а не третий навык. Его установка и совместимость с конкретным SaaS не подтверждены.
