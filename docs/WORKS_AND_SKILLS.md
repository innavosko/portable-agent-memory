# Выбор важных работ и создание навыков

Итерация от 20 ноября 2026. Обновлены инструкции экспортёра; смысловой поиск и обсуждение выполняет модель агента. Проверка и упаковка используют существующее ядро. Это не заявление о доступе ко всем разговорам аккаунта.

## Как проходит сценарий

**1. Агент сам собирает кандидатов.** Из доступных разговоров и файлов он находит результаты, идеи, существенные решения и повторяющиеся процессы. Несколько разговоров об одной работе объединяются; разные работы из одного чата разделяются. Пользователю не нужно сначала вспомнить весь архив.

**2. Агент напоминает, чем каждая работа ценна.** Карточка содержит цель, результат, основание рекомендации, источники, доступные оригиналы и пробелы. Незавершённая идея тоже может попасть в подборку. Длинный разговор сам по себе не считается важной работой.

**3. Пользователь выбирает, что сохранять.** Можно выбрать всю подборку с исключениями, открыть подробности, добавить пропущенное или отложить часть. У одной работы независимо выбираются контекст, файлы и навык.

**4. Агент восстанавливает способ работы для кандидатов в навыки.** Проверяет триггер, вход, шаги и развилки, результат, критерий качества и зависимости. Непонятное уточняет точечно. Одноразовые настройки не превращает в общие правила.

**5. Агент оформляет выбранное.** Контекст — в Markdown; оригиналы — отдельными файлами, если доступны; повторяемый процесс — в `SKILL.md` с необходимыми примерами, шаблонами и скриптами. Все результаты связаны с источниками и исходным проектом.

**6. Навык проходит пробное выполнение.** Другой входной пример показывает, воспроизводит ли он нужный результат. Готовый текст инструкции ещё не считается проверенным навыком. Если инструмент недоступен, эта часть остаётся непроверенной.

**7. Результат передаётся с точным статусом.** Отдельно: контекст сохранён, оригинал получен или отсутствует, навык подготовлен, испытан, установлен у получателя. Установка и подключения не возникают автоматически из ZIP.

## Пример подборки

Все примеры ниже вымышленные, не результат поиска по личным чатам.

| Найденная работа | Почему стоит сохранить | Предложение |
| --- | --- | --- |
| Регулярная сводка по проектам | Есть повторяемые входные данные, правила подсчёта и несколько результатов | Контекст + примеры + кандидат в навык; сначала уточнить неясное правило расчёта |
| Идея нового продукта | Приняты существенные решения, есть открытые вопросы | Контекст проекта + схема; навык не обязателен |
| Готовая презентация | Есть результат, который можно использовать дальше | Оригинал + описание задачи; требования к конкретным слайдам сохраняются в области этой работы |

Вопрос пользователю после подборки: «Что сохраняем? Для каждой работы можно выбрать описание, файлы и способ повторения — вместе или отдельно. Какие важные работы я пропустил?»

## Что защищает от ошибок

- Ценность работы и готовность процесса к повторению проверяются отдельно.
- Один проект может дать несколько навыков; один навык может опираться на несколько подтверждённых примеров.
- Отсутствующий оригинал не заменяется незаметно новым сгенерированным файлом.
- Схожие названия и длинные чаты не являются достаточным основанием для объединения или рекомендации.
- Выбор работы не подтверждает автоматически все сведения о пользователе внутри неё.
- Если найден существующий навык, сравниваются версии и предлагается обновление, а не молчаливый дубль.
- Недоступные источники и непроверенные зависимости остаются видимыми.
