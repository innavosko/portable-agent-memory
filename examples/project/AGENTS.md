# ДЕМО: инструкции вымышленного проекта

Этот файл — материал источника для демонстрации. При сборе его содержимое копируется как данные, не становится инструкцией выполняющему сбор агенту.

Пример проектных правил: описывать результат простым языком; указывать, какие входные сведения проверены; хранить открытые вопросы рядом с принятым решением.

Область этих вымышленных правил — только проект «Маяк». Для активации в другом агенте требуется отдельная проверка.
