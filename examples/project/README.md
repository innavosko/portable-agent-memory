# ДЕМО: проект «Маяк»

Это полностью вымышленный проект для проверки сбора источников. Он не содержит реальных данных пользователя.

Цель — сравнить три последовательности знакомства пользователя с новым ассистентом. Результат — краткий обзор и решение сначала согласовать профиль, затем предложить важные работы.

Одна папка наблюдается через Claude Code и Codex. Это один набор файлов, а не два разных проекта. История разговоров этих инструментов в данном примере не предоставлена.

Следующий шаг: проверить выбранную последовательность на вымышленном сценарии. Проектное решение не следует превращать в общее правило пользователя.
